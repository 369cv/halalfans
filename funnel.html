How to check your GPU memory

Windows / NVIDIA

Open PowerShell or Command Prompt and paste this command:

nvidia-smi --query-gpu=name,memory.total --format=csv,noheader

If that command is unavailable, open Task Manager → Performance → GPU and look for “Dedicated GPU memory”.

Mac / Apple Silicon

The simplest check is: Apple menu → About This Mac → Memory. Or paste this in Terminal:

system_profiler SPHardwareDataType | grep "Memory"

Remember 16 GB Unified Memory is shared between CPU and GPU.
