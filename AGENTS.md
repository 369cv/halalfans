# Chrome Extensions Workspace Instructions

This workspace is dedicated to building, refining, and publishing production-grade Chrome extensions compliant with Manifest V3 and the official [Chrome Web Store Documentation](https://developer.chrome.com/docs/webstore?hl=en).

## Operational Directives:
1. **Skill Integration**: Reference and apply the `chrome-extension-builder` (and `chrome-extensions`) skills for all architecture patterns, API usage, and packaging workflows.
2. **Turn One Execution**: When transforming any concept, idea, feature, or design reference into a Chrome extension, deliver complete, runnable, fully styled, and verified code with zero broken assets or placeholders.
3. **Store Compliance**: Maintain `CHROMEWEBSTORE.md` with up-to-date metadata, plain-English permissions justifications, asset tracking, and privacy disclosures.
4. **Manifest V3 Standards**: Ensure strictly scoped permissions, ephemeral service worker state persistence via `chrome.storage`, clean async message handling, and no forbidden inline scripts or remote code.
